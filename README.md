# MyNotes

SPA для заметок-чек-листов. Две страницы: список и редактор. Сервера с данными нет — всё хранится в браузере.

## Что умеет

На главной — карточки сохранённых заметок: заголовок и превью пунктов. Пустой заголовок показывается как «Без названия». Отсюда можно создать заметку, открыть её или удалить (с подтверждением).

В редакторе — название и список дел: пункт добавляется, правится, отмечается и удаляется. Пустую строку в список не пускает; если текст стерли и ушли с поля, пункт пропадает. Сохранить записывает заметку в список. Отменить сбрасывает несохранённые правки (если они есть — сначала спрашивает). Удалить убирает заметку из списка.

Правки можно откатить и вернуть: Ctrl+Z / Shift+Ctrl+Z. Несохранённое редактирование переживает перезагрузку страницы — предлагается восстановить черновик или отбросить его. Если ту же заметку удалили в другой вкладке, редактор сообщает об этом и возвращает к списку.

## Запуск

Нужны Node 22+ и pnpm 10.

```bash
pnpm install
pnpm dev
```

http://localhost:3000

`pnpm lint`, `pnpm typecheck`, `pnpm test`.

```bash
docker compose up --build
```

http://localhost:8080

## Как устроено

Pinia хранит только сохранённые заметки. Черновик и отмена правок живут в сессии редактора и попадают в стор только по «Сохранить».

Подробности — в [docs/architecture.md](docs/architecture.md).

## Ограничения ТЗ

Не использовали UI-киты, библиотеки undo/redo, persist-плагины Pinia и `alert`/`confirm`. Свои компоненты, свой persist, свои модалки.

История — патчи, не полные копии заметки: undo знает, что изменилось, ввод в одно поле — один шаг, без 50 снимков целиком.
